HOW TO PREVIEW
1. Keep both files in the same folder.
2. Open index.html in a modern browser.
3. Click “Tee Off”, then “Enter Our Wedding”.

This is a website animation prototype, not a finished 6–8 second MP4. The golfer image is a still visual from a generated storyboard; the golf ball and crack/shard transition are CSS animations. It does not currently include actual video motion, recorded sound, or physically simulated glass.
