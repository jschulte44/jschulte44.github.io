DREW & MONIQUE — TEE OFF WEDDING INTRO

FILES
- index.html: interactive website prototype (HTML/CSS/JS)
- drew_monique_golfer_keyframe.jpg: visual reference for the golfer opening
- drew_monique_mountain_course.jpg: scenic visual reference for the reveal and hero

HOW TO PREVIEW
1. Keep all three files in the same folder.
2. Open index.html in a modern browser.
3. Click “Tee Off” to play the prototype. Click “Enter our wedding” to view the sample homepage.

WHAT THIS IS
This is a working web-animation prototype with a CSS golf-ball flight, stylized crack overlay, reveal, and sample homepage. The included images are generated storyboard/keyframe crops, not continuous video footage. This package does not include a real filmed swing, physically simulated flying glass, or a cinematic music track. Browser audio is not included yet; add licensed sound effects/music during video finishing or via a separate audio file after confirming usage rights.

CUSTOMIZE
Edit names/date/location/tagline in index.html. Replace the two JPGs with final licensed/generated images or video assets if you commission them. For the strongest result, ask a motion designer to deliver a 6–8 second 1080p MP4 (H.264) with the swing, ball flight, glass shatter, and sound design. Then the page can use that MP4 as the intro video, with this HTML handling the “Tee Off” click and website reveal.

PUBLISH
Upload the folder to a static host such as GitHub Pages or Netlify. For a custom domain, configure it with the chosen host. Before public launch, replace placeholder website sections with real venue, travel, RSVP, registry, and FAQ links.
